# Finance Capstone Project

A comprehensive financial analysis toolkit for risk and performance metrics.

## Features

- Daily and log returns calculation
- Risk metrics (VaR, CVaR, volatility)
- Performance metrics (Sharpe ratio, Sortino ratio)
- Statistical tests (ADF test for stationarity)
- Interactive Streamlit dashboard
